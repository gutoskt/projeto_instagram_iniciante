# 📸 Instagram Clone (Sujeitogram)

> Reprodução visual da interface do Instagram desenvolvida para praticar conceitos fundamentais de layout, estilização e responsividade na web.

---

## 📌 Sobre o Projeto

O **projeto_instagram_iniciante** (também chamado de **Sujeitogram**) é uma reprodução da interface web do Instagram. Criei este projeto com o intuito de consolidar e aperfeiçoar meus conhecimentos na construção de layouts modernos e fiéis ao design original de grandes redes sociais.

Durante o desenvolvimento, foquei em alinhar perfeitamente elementos visuais, trabalhar a hierarquia das páginas (login e cadastro), estruturar formulários funcionais e garantir que a interface reagisse bem a diferentes tamanhos de tela.

---

## ✨ Funcionalidades

- **Tela de Login:** Formulário estruturado com campos para usuário/email e senha.
- **Tela de Cadastro:** Interface dedicada para novos usuários com formulário completo.
- **Moldura Mobile (Mockup):** Exibição dinâmica simulando a navegação em um dispositivo smartphone.
- **Navegação Simples:** Alternância entre as telas de login e cadastro.
- **Design Responsivo:** Adaptação do layout para visualização em telas menores (smartphones e tablets) e maiores (desktops).

---

## 🛠️ Tecnologias Utilizadas

Para este projeto, utilizei as tecnologias fundamentais da Web:

- **HTML5:** Estruturação semântica de formulários, seções, rodapé e links.
- **CSS3:** Estilização avançada utilizando **Flexbox**, alinhamentos, posicionamento de elementos, sombras e media queries para responsividade.
- **JavaScript:** Manipulação básica da DOM para comportamentos da interface e navegação entre telas.

## 🚀 Como Executar o Projeto

Este é um projeto web estático, então você pode executá-lo diretamente no navegador sem a necessidade de instalar dependências complexas.

### Passos:

```bash
# 1. Clone este repositório
$ git clone [https://github.com/gutoskt/projeto_instagram_iniciante.git](https://github.com/gutoskt/projeto_instagram_iniciante.git)

# 2. Acesse a pasta do projeto
$ cd projeto_instagram_iniciante

# 3. Abra o arquivo index.html no seu navegador favorito

```
Se estiver usando o **VS Code**, clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.
